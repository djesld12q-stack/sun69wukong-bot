СЛЕШ-КОМАНДИ БОТА

Вводь у Discord після того як бот доданий на сервер. Всі команди починаються з /

📡 Twitch — статус стріму
/status[username]
Перевірити чи стрімер зараз онлайн / офлайн. Якщо без username — бере першого зі списку.
/uptime[username]
Скільки часу вже йде поточний стрім.
/stats[username]
Повна статистика: гра, глядачі, тривалість, теги, мова.
/viewers[username]
Поточна кількість глядачів стріму.
/game[username]
Яку гру зараз стрімить стрімер і назва стріму.
/streamers
Список всіх стрімерів цього сервера та їх статус.
🎬 Twitch — контент
/clips[username][count]
Останні кліпи стрімера. count — кількість (1–5, за замовчуванням 3).
/top_clips[username]
Топ 5 кліпів стрімера відсортованих за переглядами.
/profile[username]
Профіль стрімера: аватар, фоловери, тип каналу, дата реєстрації.
/schedule[username]
Розклад стрімів на найближчі дні (якщо стрімер його заповнив).
/searchquery
Пошук живих стрімерів за запитом на Twitch.
/top_streamsgame
Топ 5 стрімів по вказаній грі прямо зараз.

⚡ Як AI перевіряє кожне повідомлення
1
Швидкий pre-filter — унікальні рос. символи ё ъ ы э? Миттєво блокуємо без API-виклику.
2
Немає кирилиці? — пропускаємо (latin, emoji, числа — не рос.).
3
Дуже короткий текст? — менше 6 символів: не витрачаємо токени на AI.
4
AI-аналіз — текст надсилається до провайдера з чітким промптом. Модель відрізняє «Привіт» (укр.) від «Привет» (рос.), болгарську від сербської тощо. Таймаут 5с + кеш 500 записів.
Налаштування в .env
# Вибір провайдера (ollama | gemini | openai | anthropic)
AUTOMOD_AI_PROVIDER=ollama
AUTOMOD_AI_MODEL=llama3.2
# Тільки для Ollama (URL сервера)
AUTOMOD_AI_BASE_URL=http://localhost:11434
# API ключі (лише для хмарних провайдерів)
GEMINI_API_KEY=AIza...
OPENAI_API_KEY=sk-...
ANTHROPIC_API_KEY=sk-ant-...
⚙️ Головні налаштування
/automod_setup NEW [enabled] [block_russian] [keywords] [log_channel] [warn_message]
Головна команда конфігурації AutoMod. У відповіді бот показує активний AI-провайдер і модель.
▸ enabled: так — активувати автомодерацію
▸ block_russian: так — AI-детектор російської мови (з вибором провайдера в .env)
▸ keywords: слово1,слово2 — додаткові заборонені слова
▸ log_channel — канал для embed-логів порушень
🔑 Керування ключовими словами
/automod_keywords NEW action [words]
Динамічне керування списком заборонених слів.
▸ add слово1,слово2 — додати
▸ remove слово — видалити
▸ list — переглянути (ephemeral)
▸ clear — очистити все
🔓 Виключення з модерації

Налаштувати ролі та канали які AutoMod ігнорує. Корисно для @Модератор, #off-topic тощо.
▸ exempt_role / exempt_channel — додати виключення
▸ remove_role / remove_channel — прибрати виключення

🎯 Що саме перевіряє AutoMod
🤖
AI-детектор мови — надсилає текст до вибраного провайдера (Ollama/Gemini/OpenAI/Anthropic). Модель розуміє контекст: «Привіт» (укр.) ≠ «Привет» (рос.), ігнорує латиницю, emojis, числа. При помилці API — пропускає без блокування (conservative fallback).
🇷🇺
Швидкий pre-filter — унікальні символи ё ъ ы э спрацьовують миттєво без API. Економія токенів і затримки нуль.
🔑
Заборонені слова — незалежно від регістру, знаходить навіть всередині речення. Перевіряється до AI-детектора.
🗑️
При порушенні — повідомлення видаляється, порушнику надсилається попередження у канал (зникає за 8с), у лог-канал надходить embed з причиною та назвою AI-провайдера.
