📋 Всі команди

СЛЕШ-КОМАНДИ БОТА

Вводь у Discord після того як бот доданий на сервер. Всі команди починаються з /

/status [username]
Перевірити чи стрімер зараз онлайн / офлайн. Якщо без username — бере першого зі списку.
/ping
Затримка бота, статус і кількість серверів.
/uptime [username]
Скільки часу вже йде поточний стрім.
/stats [username]
Повна статистика: гра, глядачі, тривалість, теги, мова.
/viewers [username]
Поточна кількість глядачів стріму.
/game [username]
Яку гру зараз стрімить стрімер і назва стріму.
/streamers
Список всіх стрімерів цього сервера та їх статус.
/clips [username] [count]
Останні кліпи стрімера. count — кількість (1–5, за замовчуванням 3).
/top_clips [username]
Топ 5 кліпів стрімера відсортованих за переглядами.
/profile [username]
Профіль стрімера: аватар, фоловери, тип каналу, дата реєстрації.
/schedule [username]
Розклад стрімів на найближчі дні (якщо стрімер його заповнив).
/search query
Пошук живих стрімерів за запитом на Twitch.
/top_streams game
Топ 5 стрімів по вказаній грі прямо зараз.
🔐 Ці команди доступні тільки учасникам з правом Адміністратор на сервері.
⚙️ Початкове налаштування
/setup_channel channel
Встановити дефолтний канал для анонсів на весь сервер.
/setup_role role
Дефолтна роль яка отримує пінг при анонсі стрімера.
/setup_tokens twitch_token [client_id]
Встановити Twitch токен для цього сервера. Отримай токен на twitchtokengenerator.com.
/token_status
Перевірити чи валідний поточний Twitch токен сервера.
👥 Управління стрімерами
/streamer_add username [channel] [role] [discord_member]
Додати стрімера до моніторингу. Опціонально вказати канал, роль для пінгу та Discord-акаунт для live ролі.
/streamer_remove username
Видалити стрімера зі списку моніторингу.
/streamer_toggle username
Тимчасово вимкнути або знову увімкнути моніторинг конкретного стрімера.
/set_channel username channel
Встановити індивідуальний канал анонсів для конкретного стрімера.
/set_role username role
Встановити роль для пінгу для конкретного стрімера.
🎨 Налаштування вигляду
/set_prefix [username] [online_prefix] [offline_prefix]
Змінити текст над embed. Якщо без username — змінює для всього сервера. Приклад: 🔴 Стрімер онлайн!
/set_config key value
Розширене налаштування: embed_color, embed_title, embed_show_game та інші параметри.
/offline_toggle
Увімкнути або вимкнути повідомлення коли стрімер іде офлайн.
🔧 Утиліти та тест
/test_embed
Надіслати тестове embed-повідомлення в канал щоб перевірити вигляд.
/force_check
Примусово перевірити статус всіх стрімерів прямо зараз.
/announce_now [username]
Примусово надіслати анонс стрімера в канал (навіть якщо офлайн — використає останній snapshot).
/clear_state [username]
Очистити збережений стан стрімера. Без username — очищає всіх. Корисно при багах.
🎭 Live Роль та Events
/set_live_role [role]
Роль яку бот автоматично дає стрімеру поки він LIVE. Без аргументу — прибирає роль.
/set_discord_member username [member]
Прив'язати Discord-акаунт до Twitch стрімера (потрібно для видачі live ролі).
/live_role_status
Переглянути всі прив'язки Discord↔Twitch та стан live ролі.
/event_toggle
Увімкнути або вимкнути автоматичне створення Discord Events при старті стріму.
/create_event [username]
Вручну створити Discord Event для стрімера (навіть якщо він офлайн).
